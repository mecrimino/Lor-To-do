# Changelog

All notable changes to **LOR TO-DO** will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-10-01

### Added
- **Core Task Engine**: Tasks, checklists/subtasks, priority levels, notes, tags, and custom lists.
- **Natural Language Quick-Add**: Rule-based offline parser for dates, times, priorities (`!high`), tags (`#bills`), and recurrence (`every month`).
- **Modern Jetpack Compose UI**: Dynamic Material You theming, Warm Amber palette, AMOLED true black mode.
- **Header & Date Strip**: Cheerful greeting header with horizontal interactive weekly date picker.
- **Smart Views**: Today, Inbox, Tomorrow, Upcoming (7 days), Overdue, Starred, All, and Completed views.
- **Calendar & Kanban Views**: Full monthly calendar with indicator dots and visual Kanban boards.
- **Pomodoro Focus Timer**: Customizable work and break cycles linked directly to tasks.
- **Productivity Dashboard**: Statistics, completion rates, and habit streaks.
- **Exact Reminders & Housekeeping**: AlarmManager exact alarms, boot rescheduling receiver, WorkManager 30-day trash auto-cleanup.
- **Biometric Security**: App lock via fingerprint/face/PIN and screenshot privacy toggle.
- **Open Data Ownership**: Full JSON, CSV, and Markdown export & import via Storage Access Framework.
- **Home Screen Widgets**: Jetpack Glance widget with interactive task completion and quick add.
- **Share Target & Quick Settings Tile**: Instant task capture from other apps and system drawer.
